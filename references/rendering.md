# 页面结构与图表规格

## 一、单文件 HTML 的数据数组

页面所有数字都从四个数组读，换数据只改这四处。

```js
// A股快照（37 条）
{ n:'通信(5G)', g:'行业', chg:0.08, ytd:5.08, s924:152.87, pe:41.46, t:63.7263, prev:63.5352, etf:'515880' }
//   n 名称 | g 行业/宽基 | chg 当日% | ytd 今年以来% | s924 2024-09-24以来%
//   pe 当日PE(TTM) | t 温度(=PE十年分位, 0-100) | prev 上一交易日温度 | etf 相关标的

const H = [ /* 港股 7 条，字段相同 */ ];

// A股十年序列，[日期, 温度, 参与标的数]
const TH  = [ ['2016-12-30', 55.14], ... ];
const THH = [ ['2016-12-30', 51.36, 2], ... ];
```

**表格列（2026-10 起）：**序 / 行业名称 / 今年以来 / 924以来 / 当日PE / 行业温度 / 相关标的。
**「当日涨幅」列已按博格要求去掉**，`chg` 字段仍留在数组里（取数时顺手带上，便于核对），只是不再渲染；默认排序为**按行业温度升序（冷 → 热）**，`sortKey='t', sortAsc=true`。别再把它加回去。

`null` 表示该日无数据（如新股上市不足），表格里显示为「—」，排序时排末尾。`pct()` 和排序比较器都要做 null 安全。

## 二、温度计（SVG）

`viewBox="0 0 236 372"` 手绘，不用图表库。右侧那 72px 是给「50° 以上开始卖出（不可提高仓位）」两行标注留的，标注块 `rect` 从 x=104 起、宽 126。

- 管身：圆角矩形 + 底部球形，深色描边，内部按温度填充
- 填充色：`tempColor(t)` 六段插值 —— 0 冷蓝 `#3b8bd9` → 25 青 `#2eaaa0` → 35 绿 `#34b37e` → 50 黄 `#f0b429` → 70 橙 `#ea6a3a` → 100 红 `#d4372f`
- 刻度：0/20/40/60/80/100 在左侧
- **30 / 50 两个阈值标注要分两行**，并从文字拉一条虚线引出到管身，否则会压在刻度上

### 改字号的连带影响

把页面字号整体放大约 15% 时，温度计会出两个问题，必须一起改：

1. **标注文字被 SVG 自己裁掉。** SVG 默认 `overflow:hidden`，`viewBox` 宽度不变而字变大，右侧标注直接被切。同步加宽 `viewBox`（212 → 236）和标注块 `rect`（102 → 126）。
2. **卡片放不下，整支温度计被挤出右边框。** 卡片是 `justify-content:space-between`，左列数字一旦变宽就把温度计顶出去。把 `.tcard svg` 的 `height` 从 372 降到 344（宽度按比例跟着缩），内边距从 `18px 16px 14px 22px` 收到 `14px 12px 12px 18px`，能腾出约 40px。

当前字号基线（1080 宽长图下实测可读）：正文/表格 14px、说明 13px、小标签 12px、大标题 58px、温度数字 58px、图表刻度 11–12.5px。

## 三、十年走势图

`renderHist(o)` 一个函数画两张图，靠参数区分：

| 参数 | 说明 |
|---|---|
| `data` | TH 或 THH |
| `sfx` | `'a'` / `'h'`，用于生成唯一的渐变 id |
| `svgId` / `barId` / `tipId` | DOM 挂载点 |
| `w` / `h` | 画布尺寸。并排用 460×300，单栏用 944×268 |
| `ml` / `mr` / `mt` / `mb` | 边距，窄版默认 25/16/24/22 |
| `compact` | 窄版开关：字号缩小、年份隔年标注、参考线文字交给图例 |

要点：

- **曲线用 Catmull-Rom 转贝塞尔**，k=0.32 轻度平滑。直接连折线会显得生硬，过度平滑又会吃掉真实的尖峰。
- **面积渐变跟随 Y 轴**（`gradientUnits="userSpaceOnUse"`），上红下蓝，这样峰谷的色温是自洽的。
- **悬停十字线**：透明 `<rect>` 接 `mousemove`，按 x 反查最近点，显示日期 + 温度 + 标的数。
- **极值/当前值标签必须加白色描边**：`stroke="#fff" stroke-width="2.6~3" paint-order="stroke"`。不加的话，末端点正好落在 50° 线上时会和标签糊成一团。

### 并排的两个坑

1. **整数缩放会把字号压到 5px。** 944 宽的 viewBox 塞进 450px 的格子，视觉字号直接不可读。必须另设窄版 viewBox（460×300）并重配字号，不能靠 CSS 缩放。
2. **参考线文字贴右轴会被末端点压住。** 30°/50° 的说明文字从图上移走，改到图下方用 `.duo-legend` 图例行承担。

窄屏（≤860px）回落单栏，这是唯一的响应式断点。

## 四、配色

```
底 #f6f7f9   卡片 #fff      墨 #141e2c
红 #d4372f   橙 #ea6a3a     黄 #f0b429
绿 #34b37e   青 #2eaaa0     蓝 #3b8bd9
```

温度色沿用 `tempColor` 的六段插值，保证温度计、曲线、表格里的色条是同一套。

数字统一 `font-variant-numeric: tabular-nums`，否则表格各行的位数跳动会显得很脏。

## 五、字号基线

以下都是 **CSS 像素**（视口 1080 宽；高清图按 2x 输出，视觉比例不变）。改字号时按这个改，别只改一处：

| 位置 | 字号 |
|---|---|
| 温度数字 `.tnum` | 64px |
| 页头主标题 `.brand-t` | 40px（字重 800，`letter-spacing:-1.2px`） |
| 卡片标题 `.tlabel` | 26px（字重 700，带 4×20px 色条） |
| 走势标题 `.duo-t` | 24px（字重 700，带 4×19px 色条） |
| 分项温度小标题 `.sec-t` | 23px |
| 分项温度表格正文 | 21px |
| 表格表头 | 18px |
| 分项副标题 / 右上角说明 | 17.5px |
| 正文/说明 | 14px |
| 注释脚注 | 13px |
| 图表坐标刻度 | 11–12.5px |

14px 是 1080 宽下的可读下限。表格比正文大得多是故意的——它是这张图的主体，读者会盯着它看。2026-10 博格要求「分项温度区字体加大两个字号」，表格正文从 17px 提到 21px，其余配套抬高：表头 18px、小标题 23px、标的标签 14.5px、港股表注 15px，温度条同步放大到 46×6px，名称列宽度从 24% 放到 28% 以免长名字省略成「…」。再往上加会撑破 1080 宽，先改宽度分配再动字号。

### 标题层级（2026-10-19 重做）

博格的原话是「A股市场温度 / 港股市场温度、望京博格的市场温度计、A股 十年温度走势 文字不够显著」。原版三个标题分别是 14px 灰字、21.5px、15.5px，全被 58px 的温度数字压住。改法不是单纯调大，而是重建层级：

- **页头**：21.5 → 40px、字重 700 → 800，`博` 徽标 30 → 42px，日期 17 → 21px。
- **卡片标题**：14px 灰色 → 26px 加粗、用墨色，并在前面加 4×20px 的色条（A股红、港股蓝），跟分项小标题、走势标题用同一套「色条 + 粗标题」语言。
- **标的数**：原来挤在标题右侧做 `<span>`，26px 时会把标签挤出卡片（`.tlabel` 白字 nowrap 被 `overflow:hidden` 裁掉）。改成独立一行的 `.tpill`（13px 药丸），标题因此能用满整行。
- **走势标题**：15.5 → 24px，色条 3×12 → 4×19，下面的「最高/最低/均值」从 12/14px 提到 13.5/15.5px，否则相对标题显小。

改这组字号会连带两处：`.tcard svg` 高度从 344 降到 336（标题变宽会挤温度计），卡片总高 364、整页 CSS 高 3452。要再放大标题，先减温度计高度或改双栏为单栏，别硬塞。


## 六、文案口径（不要改）

- 30° 以下 → **开始买入（可提高仓位）**
- 50° 以上 → **开始卖出（不可提高仓位）**
- 配两句对冲：开始买入 ≠ 直接满仓；开始卖出 ≠ 立刻清仓

博格特意把「卖出」改成「开始卖出（不可提高仓位）」，语义是"不再加"，不是"清仓"。这层意思丢了，页面就变味了。
